Titanic Streamlit Application 

This project provides a simple Streamlit application that predicts Titanic passenger survival using a RandomForest model. The code mimics a beginner's style while remaining functional.

Usage
Create and activate a Python virtual environment.
Install dependencies:
pip install -r requirements.txt
Place titanic.csv in the same directory as app.py.
Run the application:
streamlit run app.py

The app collects passenger information via a form and displays the survival prediction.

This README offers a quick overview to get the project up and running.
